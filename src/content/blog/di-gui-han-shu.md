> 递归的核心：**把大问题拆成同结构的小问题**，并且**保证能停下来**。本文按「概念 → 设计要点 → 风险 → 优化」整理。


## 什么是递归？


递归函数：在函数内部**直接或间接调用自身**。


示例：阶乘（直接递归）


```javascript
function fact(n) {
  if (n === 1) return 1; // 结束条件
  return fact(n - 1) * n;
}
```


---


## 递归的两种调用方式


### 1）直接调用（自己调用自己）


```javascript
function func(n) {
  if (n === 1) return 1;
  return func(n - 1) * n;
}
```


### 2）间接调用（A 调 B，B 又调回 A）


```javascript
function fun1(a) {
  return fun2(a + 1);
}

function fun2(s) {
  return fun1(s - 1);
}
```


---


## 如何设计递归函数？（四要素）

1. **结束条件（Base case）**：必须能命中，否则无限递归
2. **拆分子问题**：把原问题转换为规模更小、结构相同的子问题
3. **趋近结束条件**：每次递归都要让规模变小（例如 `n-1`）
4. **返回值与合并（Combine）**：递归返回的结果要能被上层利用并合并成最终答案

---


## 递归的缺点/风险

1. **空间开销大**：每层调用都会占用调用栈
2. **可能栈溢出**：递归层数过深时容易触发
3. **重复计算**：子问题重叠时会做很多无用功

---


## 如何优化递归？

- **尾递归**（依赖语言/运行时是否做 TCO）
- **用循环替代递归**（迭代写法，减少调用栈）
- **记忆化 / 动态规划**（缓存子问题结果，避免重复计算）
